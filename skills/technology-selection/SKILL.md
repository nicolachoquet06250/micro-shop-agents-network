# Skill `technology-selection`

## Méthode

Évalue les technologies sur des critères objectifs :

1. compatibilité avec le dépôt existant ;
2. adéquation au rendering requis ;
3. SEO ;
4. complexité du back-office ;
5. contraintes de runtime ;
6. base de données ;
7. intégrations requises ;
8. maturité de l'écosystème ;
9. testabilité ;
10. maintenabilité ;
11. performance ;
12. simplicité opérationnelle.

## Règle

Une exigence explicite de l'utilisateur prime sur une préférence technologique générale.

Ne conserve pas une stack par défaut uniquement par habitude.

## Sortie

Toujours expliquer les choix et alternatives rejetées brièvement.
