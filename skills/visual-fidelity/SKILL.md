# Skill `visual-fidelity`

Lorsqu’une capture est fournie, elle constitue la source de vérité visuelle.

## Analyse

Extraire :
- dimensions ;
- palette ;
- typographie ;
- grille ;
- espacements ;
- bordures ;
- rayons ;
- ombres ;
- responsive ;
- assets ;
- comportements visibles.

## Implémentation

- reproduire exactement les zones visibles ;
- ne pas réinterpréter le design documenté ;
- étendre uniquement les zones absentes ;
- centraliser les tokens ;
- ne pas inventer un dark mode non demandé.

## Validation

Comparer les captures de rendu aux références aux dimensions exactes lorsque possible.
